sMaptic - Homepage

Welcome to sMaptic!

sMaptic is a map loader mod for SNAPTIC Demo!

This mod allows you to import maps in the form of .zip files that have been exported from the Godot editor directly into SNAPTIC, without touching any code or installing multiple mods! Maps can be shared and downloaded via the official sMaptic Map Index, and imported in-game into your personal custom maps list. Custom maps are extremely flexible and can contain almost anything!
